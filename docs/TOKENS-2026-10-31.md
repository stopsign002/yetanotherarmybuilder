# Style unification pass — 2026-10-31 (contract)

Goal: fewer distinct values, not fewer rules. After the component
reorganisation `css/` still carries 77 font sizes, 189 padding values, 39
radii, 120 box-shadows, 29 letter-spacings and about 1,000 literal colours.
This pass snaps them to scales defined once in `css/tokens.css`, so a density
or type change is one edit and `themes/brutalist.css` stops restating values.

**This is a visible change by design** (13px becomes 12px or 14px, 7px
padding becomes 8px). The owner reviews it on the test site
`https://yaab-test.thewheeliebois.com` (git worktree
`~/sites/sites/yaab-test/app`, branch `tokens`, same API and data as live)
and decides. Nothing here touches live until approved.

--fs-lg: 16px;  --fs-xl: 18px; --fs-2xl: 22px; --fs-3xl: 28px; --fs-display: 48px;
/* space — padding, margin, gap, inset */
--sp-1: 2px; --sp-2: 4px; --sp-3: 6px; --sp-4: 8px; --sp-5: 10px; --sp-6: 12px;
--sp-7: 14px; --sp-8: 16px; --sp-9: 20px; --sp-10: 24px; --sp-11: 32px;
--sp-12: 40px; --sp-13: 48px; --sp-14: 56px; --sp-15: 64px;
/* radius — --radius 6px, --radius-sm 4px, --radius-lg 10px already exist */

## 2. Snapping rules (mechanical; apply to every file you own)

| property | rule |
|---|---|
| `font-size` in px | nearest scale step; ties go DOWN (15→14, 17→16, 20→18, 9→10, 12.5→12, 26→28 is the exception: up). `rem`/`em` values stay unless they equal a step at 16px base (0.75rem=12px → `--fs-sm`). `mm`/`pt`/`calc(...mm...)` (print cards) untouched. |
| `padding`, `margin`, `gap`, `top/right/bottom/left`, `inset`, `row-gap`, `column-gap` in px | each px token → nearest `--sp-*`; odd values round to the EVEN neighbour that is closer, ties DOWN (7→6? no: 7→8, 5→4, 3→2, 9→8, 1px stays 1px as a hairline, 0 stays 0). Negative margins keep their sign (`calc(-1 * var(--sp-6))`). Values with `%`, `vw`, `vh`, `em`, `rem`, `clamp()`, `auto` untouched. `820px` (a breakpoint) untouched. |
| `border-radius` | 3→`--radius-xs`, 4/5→`--radius-sm`, 6/8→`--radius`, 10/12→`--radius-lg`, 999px/9999px/100px→`--radius-pill`, `50%`/`0`/`inherit`/`calc` untouched. |
| `box-shadow` | only PLAIN elevation shadows (`0 Ypx Bpx rgba(0,0,0,a)`, possibly two layers): Y≤2→`--shadow-sm`, Y≤4→`--shadow`, Y≤10→`--shadow-lg`, else `--shadow-xl`. Coloured glows, inset shadows, focus rings, faction `var(--accent...)` shadows untouched. |
| `letter-spacing` | em: nearest `--tr-*` (0.03→tight, 0.05→normal, 0.07→wide, 0.1→wider, 0.14–0.18→widest); px: convert at the rule's font size when it is known, else 0.5px→`--tr-normal`, 1px→`--tr-wider`, 1.2–2px→`--tr-widest`. `0` stays. |
| `font-weight` | 800→700. Nothing else. |
| colours | `rgba(255,255,255,a)` → nearest `--ov-*` (.03/.04/.05→1, .06→2, .07/.08→3, .1/.12→4, .15/.18/.2→5, .25/.3→6; above .3 untouched). `rgba(0,0,0,a)` as a FILL or BORDER → nearest `--sh-*`; inside box-shadow handled above. A hex literal that equals an existing `tokens.css` colour token → that token. Everything else (faction colours, named accents, gradients, glows) untouched. |

Never change a selector, never reorder rules, never merge rules, never touch
`css/themes/`, `css/cards-mode.css` print geometry (anything in mm/pt or under
`@media print`), or `index.html`. `calc()` with a snapped px inside: replace the
px with the token (`calc(100% - var(--sp-8))`).
